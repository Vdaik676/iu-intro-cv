## 2. Три вопроса

**2.1. Какое цветовое пространство выбрано для хромакея и почему? Что было бы в RGB?**

Использовано HSV: оттенок H и насыщенность S позволяют выделять оранжевую ручку почти независимо от изменения яркости, а V оставлен открытым от 40 до 255. Для нового кадра образец `640,800,25,100` дал границы H = 0…21 и S = 199…255; после морфологии осталось 4 компоненты вместо 49 сырых, а крупнейшая компонента занимает 3.48 % кадра. В RGB пришлось бы одновременно подбирать границы B, G и R, и тень или блик на той же оранжевой поверхности заметно сильнее меняли бы все три координаты.

**2.2. Что происходит с гистограммой при γ < 1 и при γ > 1? Куда деваются обрезанные пиксели?**

При γ = 0.5 гистограмма сдвигается вправо: среднее выросло с 64.1 до 122.1, медиана с 52 до 115, а p1 с 13 до 56. При γ = 2.0 она сдвигается влево: среднее стало 22.1, медиана 11, p1 = 1, и доля чёрных пикселей выросла с 0.06 % до 0.80 %. После вычисления значения округляются и ограничиваются диапазоном uint8 0…255, поэтому несколько близких уровней могут схлопнуться в 0 или 255; на этом фото белого клиппинга во всех трёх случаях 0.00 %.

**2.3. Почему CLAHE лучше `equalizeHist` на вашем фото — по числам из 1.3? Если не лучше — что измерили и почему?**

По одному показателю σ в тенях глобальный `equalizeHist` даже немного сильнее: 15.5 против 14.5 у CLAHE при исходных 6.7. Но `equalizeHist` слишком сильно поднял светлые области: их среднее выросло с 139.0 до 229.9, тогда как CLAHE дал 156.0. Поэтому на моём кадре CLAHE выглядит более сбалансированно: он заметно раскрывает тени (их среднее 35.9 вместо 21.2), но не растягивает почти весь светлый участок к белому.

## 3. Где сломалось

Хромакей на новом `data/object.jpg` хуже всего работает на белой надписи и ярких бликах на оранжевой ручке. Образец дал высокую нижнюю границу насыщенности S = 199, поэтому белые буквы и часть бликов выпадают из маски; после морфологии внутри крупнейшей компоненты остаются 3 дыры. Помогло бы взять несколько образцов с разных участков ручки или немного снизить нижнюю границу S, а затем аккуратнее очищать лишние области морфологией.

Кроме того, `data/poster.jpg` физически немного изогнут. Одна гомография идеально выпрямляет только плоский объект, поэтому после `rectify` левый край всё равно остаётся слегка кривым — это ограничение исходного кадра, а не сортировки углов.

## 4. Команды

Всё, что лежит в `out/`, получено этими командами:

```bash
python photolab.py gamma data/dark.jpg --gamma 0.5 -o out/dark_g05.jpg --hist out/dark_g05_hist.png
python photolab.py gamma data/dark.jpg --gamma 2.0 -o out/dark_g20.jpg --hist out/dark_g20_hist.png
python photolab.py wb data/bright.jpg --method grey-world -o out/bright_gw.jpg
python photolab.py wb data/bright.jpg --method white-patch -o out/bright_wp.jpg
python photolab.py clahe data/dark.jpg --clip 2 --tiles 8 -o out/dark_clahe.jpg --compare out/dark_cmp.jpg --hist out/dark_clahe_hist.png
python photolab.py chromakey data/object.jpg --bg data/bg.jpg --sample 640,800,25,100 -o out/object_on_bg.jpg --mask out/object_mask.png
python photolab.py rotate data/poster.jpg --deg 30 -o out/poster_rot30.jpg
python photolab.py resize data/text.jpg --scale 0.25 --report -o out/text_x025.jpg
python photolab.py rectify data/poster.jpg --corners 43,63,1276,266,1325,665,16,701 --aspect 2.459 -o out/poster_front.jpg
python photolab.py resize ../../../lectures/L05-filtering/demo/iu-building.jpg --scale 0.25 --report -o out/course_iu_x025.jpg
python photolab.py chromakey ../../../lectures/L03-color-histograms/demo/ball-lamp.jpg --bg ../../../lectures/L04-geometry/demo/road-cam.jpg --lo 140,121,40 --hi 168,230,255 -o out/course_ball_on_bg.jpg --mask out/course_ball_mask.png
python photolab.py rectify ../../../lectures/L04-geometry/demo/poster-angle.jpg --corners 560,330,1250,220,1290,1010,600,840 --size 640x905 -o out/course_poster_front640.jpg
python photolab.py sheet data/dark.jpg data/bright.jpg data/object.jpg data/bg.jpg data/poster.jpg data/text.jpg out/bright_gw.jpg out/bright_wp.jpg out/course_ball_on_bg.jpg out/course_iu_x025.jpg out/course_poster_front640.jpg out/dark_clahe.jpg out/dark_cmp.jpg out/dark_g05.jpg out/dark_g20.jpg out/object_on_bg.jpg out/poster_front.jpg out/poster_rot30.jpg out/text_x025.jpg --cols 4 -o out/sheet.jpg
```
